☁️ Datos compartidos (Supabase)

Conecta una base de datos Supabase para que rankings, series, config y anuncios se compartan entre todos los jugadores. Sin esto, cada jugador ve solo sus propios datos locales.

Guarda los datos compartidos de tu proyecto. La publishable key es pública (los jugadores leen y registran su puntaje). La Secret/Service Key es secreta y solo vive en este navegador para que el admin pueda guardar series, config y anuncios. En Supabase Dashboard → Project Settings → API.

🔎 Ya viene precargado con tu proyecto y publishable key.

🖼️ Almacenamiento de imágenes (Cloudinary)

Las imágenes se suben a Cloudinary y se muestran a todos los jugadores desde una URL pública en su CDN. Así no llenas el almacenamiento local del navegador (5MB) ni pesas la base de datos de Supabase.

Cómo crearlo: Cloudinary Dashboard → Settings → Upload → Upload presets → Add upload preset, marca unsigned y define límites (formatos permitidos, tamaño máx.). El preset te permite subir imágenes sin exponer tu API Secret.

🎯 Ya viene precargado con tu cuenta ju6a1xcy y el preset gts_unsigned (creado y probado). Puedes usarlo tal cual.
